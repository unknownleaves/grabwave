Grabwave

Save videos. Record live streams.

Grabwave downloads videos and records live streams, up to 20 at a time, from a simple built-in browser.

Download
Free for Windows, macOS and Linux

Download

Windows

Windows 10 or 11 · installer (.exe)
Download for Windows
  1. Open the file you downloaded.
  2. If Windows shows "protected your PC", click More info, then Run anyway.
  3. Follow the steps, then click Finish. Grabwave opens.

macOS

Apple Silicon Macs · disk image (.dmg)
Download for Mac
  1. Open the downloaded file.
  2. Drag Grabwave onto Applications.
  3. First time only: right-click Grabwave in Applications and choose Open.

Linux

64-bit · single file (.AppImage)
Download for Linux
  1. Right-click the file, open Properties, and allow it to run as a program.
  2. Double-click it. Nothing else to install.
Grabwave is not yet signed with a paid developer certificate, so Windows and macOS show a one-time warning the first time you open it. The steps above get you past it.

What it does

Built-in browser

Browse a site, then click the Download button that appears on the video.

Live recording

Record live streams. Grabwave waits for a stream to start and saves it as it plays.

Up to 20 at once

Queue as many as you like. Twenty download or record at the same time.

Stays up to date

One click in Settings refreshes the download engine when a site changes.

Grabwave only saves content you have the right to save. Respect each site's terms and local laws.
